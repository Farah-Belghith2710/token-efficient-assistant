# Requesting software licenses
Source: IT how-to articles - last edited 30 Jul 2026

## Standard and free software
Common tools (office software, Python, VS Code) can be installed from the Software Center without a request. Any software that is not in the Software Center must pass an IT security review, which takes up to 10 working days.

## Floating licenses
MATLAB and COMSOL use floating licenses from the license server lic.kestrel-lab.example on port 27000. A license is taken when you start the program and released when you close it, so please close these programs when you are not using them. Using them off-site needs the VPN with the Full profile.

## Paid personal licenses
For paid software that is not available as a floating license, open a request in the IT portal. Your team lead must approve it and give a cost center.
